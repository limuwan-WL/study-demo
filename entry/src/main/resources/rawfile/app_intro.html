学习软件介绍

版本 v1.0 · 多角色（学生/教师/助教/管理员）· 涉及资金与权限体系

1. 背景与目标

学习通作为高校主流教学平台，当前在个人知识管理（笔记）、课表可视化、师生课堂互动、班级群协作、讲师信息沉淀、虚拟激励体系等能力上存在缺失或体验不足。学生缺少统一的笔记与课表入口，教师的课堂互动工具分散且台账能力弱，班级群功能单一，金币等激励机制缺失。

产品决策：以"课堂教学闭环 + 个人知识沉淀 + 轻量激励"为核心，新增/优化五大能力簇——

  • 学生侧：课表、笔记、讲师主页、关注、金币
  • 教师侧：签到、随堂练习、问卷、随机抽选、积分台账
  • 通用侧：班级群协作与权限
  • 全局侧：个人中心、权限隔离、资源安全、异常反馈

可观测结果：学生可在一个 App 内完成「查看课表 → 记录笔记 → 参与课堂互动 → 积累学分/金币」的完整学习闭环；教师可在班级群内发起并管理全部课堂互动任务并导出台账。

4. 学生模块

4.1 首页

FR-S-01 笔记快捷卡片：首页新增笔记快捷卡片，点击进入笔记主页。无笔记数据时卡片内展示引导文案「暂无笔记，点击进入新建」。

FR-S-02 课程卡片与课表：首页新增课程卡片，点击默认展示「本周课表」，可切换为本月视图。

课表展示规则

  • 采用表格布局，展示列：课程名称、授课地点、任课教师、上课时段。
  • 本周视图按周一至周日排布；本月视图以日历格子承载，课程以色块嵌入日期格，点击日期展开当日全部课程。
  • 不同课程自动分配区分色，配色跟随表格主题切换；学生可手动修改单门课程颜色。
  • 表格基础样式默认为白底 + 黑色边框，课表右上角提供入口切换表格主题样式。
  • 同一时段存在多门课程时进行色块叠标，悬浮弹窗展示全部课程信息。
  • 无课表数据时展示引导文案「导入课表文件，查看你的课程安排」。

FR-S-03 课表导入：课表右上角提供手动导入入口。

项规则
支持格式.ics、.xlsx
导入流程选择文件 → 预览 → 字段自动映射（支持手动调整）→ 选择模式 → 导入
导入模式覆盖导入（清空原有课表后写入）/ 追加导入（合并写入，冲突时段按导入时间优先保留后导入项 Assumption）
失败处理展示明确报错提示（如格式不支持、字段缺失、解析失败）

FR-S-04 课表存储与提醒：课表数据本地缓存并云端同步，更换设备登录自动拉取。支持为单门课程开启上课日程推送提醒。

4.2 笔记主页

布局：顶部搜索栏 + 标题「我的笔记」+ 右侧新增笔记图标；中上横向滚动展示笔记本分类；下方笔记列表。无笔记时展示「点击右上方添加笔记」。

FR-S-05 搜索与排序：全文检索笔记标题、正文、标签，模糊匹配，结果高亮关键词。列表支持按创建时间 / 修改时间排序。

FR-S-06 笔记本管理：支持自定义新增、重命名、删除、拖拽排序。自带「默认笔记本」不可删除。

FR-S-07 笔记列表项：展示标题、内容摘要、最后修改时间、所属笔记本、标签。支持左滑唤起操作：置顶、移动分类、删除、分享。

FR-S-08 笔记编辑器：

  • 支持图文、图片、拍照上传、插入链接。
  • 实时自动保存；支持自定义标签。
  • 笔记默认私有，可切换权限为「仅课程内可见」「公开」，支持生成分享链接。

FR-S-09 回收站：删除的笔记移入回收站，保留 30 天，支持恢复。永久删除操作增加二次确认。

FR-S-10 同步与冲突：笔记数据云端同步，支持离线编辑，联网后自动同步。出现版本冲突时弹窗供用户选择保留版本。

6. 通用模块（班级群）

群成员：授课教师 + 本班学生。支持自主新建班级群。

FR-C-01 群详情面板：群聊右上角功能菜单展开后展示：群成员搜索框、课程名称、授课教师、群公告、消息免打扰开关、历史文件归档、聊天记录检索、清空本地聊天记录、举报入口、全部群成员列表。底部放置红底白字「退出课程」操作按钮。

FR-C-02 建群权限：新建班级群权限默认仅授课教师可用，支持配置助教建群权限。一门课程绑定一个主班级群，教师可额外创建多个子分组群。

FR-C-03 群公告：支持富文本、附件，区分已读/未读状态，支持置顶，修改后全员推送通知。

FR-C-04 群文件：自动归档，按文档、图片、视频分类，支持按上传时间筛选，云端存储并配置过期清理策略，支持批量下载。

FR-C-05 聊天记录：检索可通过关键词、发送人、时间范围筛选云端记录；清空本地聊天记录仅删除本机缓存，云端归档记录保留。

FR-C-07 退出与解散：

  • 退出课程操作增加二次确认。
  • 学生退出后移出班级群、收回课程全部访问权限。
  • 主讲教师无法退出自身主讲课程，可移交群主、解散群聊。
  • 教师拥有移出学生权限。

8. 选择性优化建议

以下为 P2 级建议，按需排期：

  1. 笔记支持分享至班级群，支持笔记引用课件、课程视频时间节点。
  2. 课表支持一键导出为图片，方便分享。
  3. 金币新增免费获取渠道，完成平台优质内容发布任务可领取少量金币。
  4. 随堂练习支持题目随机乱序，可开启作答切屏提醒。
  5. 班级群内设置快捷签到入口，无需跳转课程页面。
  6. 讲师主页增设匿名评价区，学生可对授课教师评价。
  7. 签到、学分、练习等所有统计台账统一支持导出 Excel。
  8. 课程、签到任务、随堂练习自动汇总至个人待办清单。
